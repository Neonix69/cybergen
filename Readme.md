# CyberGen — Official Hackathon Registration Website

## Website

**Official website:** [https://cybergen-rthf.onrender.com/](https://cybergen-rthf.onrender.com/)

## Overview

CyberGen is a hackathon registration website. Participants can visit the website to learn about the event and access the registration process.

## Purpose

- Provide a central online destination for the CyberGen hackathon.
- Share event and participation information.
- Direct interested participants to the registration process.

## How to Register

1. Open the [CyberGen website](https://cybergen-rthf.onrender.com/).
2. Review the event information and any participation requirements shown on the website.
3. Follow the on-page registration instructions and submit the requested details.

## Important Note

For the latest information about eligibility, team size, event dates, deadlines, rules, and contact details, refer to the official website. These details are not listed here because they should be confirmed from the live event page.
